Privacy

No analytics, no cookies, no third party scripts, no account. This page exists to say that precisely rather than vaguely.

Updated 2026-07-30

What this site collects

Nothing. ConnectorZone is a static site. There is no account system, no form that submits to us, no comment system and no newsletter.

Cookies

None are set. There is no consent banner because there is nothing to consent to.

Analytics and tracking

There is no analytics product on this site, first party or third party. No page view counter, no session recorder, no heatmap, no advertising pixel and no fingerprinting.

Third party requests

Loading a page on this site makes requests to this origin only. Fonts are self hosted. Images are generated at build time and served from here. The search index is a static JSON file on this origin, fetched only when you use the search box.

Links to publisher repositories, vendor documentation and other external sites are ordinary links. Following one takes you to that site, which has its own privacy practices.

Server logs

The site is served by a static host. That host may keep standard request logs, including IP address and user agent, for operational and abuse prevention purposes. ConnectorZone does not read, export or process those logs.

Data about connectors

Connector records come from the official Model Context Protocol Registry and are public data published by their authors under CC0 1.0. If you are a publisher and want a record changed, change it in the registry, or contact us through the report page.

Changes

If any of the above changes, this page will be updated before the change ships, and the update date at the top will move. The full history is in therepository.
