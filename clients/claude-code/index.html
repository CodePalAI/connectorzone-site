Claude Code

The Claude Code CLI adds servers from the command line and can commit a project scoped .mcp.json alongside your source.

  • Anthropic

What it does well

  • Project scoped servers live in the repository, so a team shares one reviewed setup.
  • Local, project and user scopes let you separate personal keys from shared configuration.
  • Remote servers can be registered with a single command including custom headers.

What catches people out

  • Project scoped servers prompt for approval the first time a teammate runs them.
  • Secrets belong in your shell environment rather than in a committed .mcp.json.

A working example

This is the real block for AIOProductOS MCP, generated from its registry record. Every connector profile produces the same thing for whichever client you are using.

.mcp.json in the repository root
{
  "mcpServers": {
    "mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@aioproductoscom/mcp@0.18.0"
      ],
      "env": {
        "PRODUCTOS_TOKEN": "<your-productos-token>"
      }
    }
  }
}
Command line
claude mcp add mcp --env PRODUCTOS_TOKEN=<your-productos-token> -- npx -y @aioproductoscom/mcp@0.18.0

Setting up a server

  1. Run the command below from the repository you want the server available in.
  2. Confirm registration with claude mcp list.
  3. Start claude and check that the server appears under the /mcp command.
