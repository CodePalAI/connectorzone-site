Claude Desktop

The desktop Claude app reads local servers from a JSON file and accepts remote servers through its connector settings screen.

~/Library/Application Support/Claude/claude_desktop_config.json

Claude Code

The Claude Code CLI adds servers from the command line and can commit a project scoped .mcp.json alongside your source.

.mcp.json in the repository root

ChatGPT and the OpenAI API

ChatGPT connectors and the OpenAI Responses API both attach remote MCP servers by URL. Neither runs a local process for you.

Settings, then Connectors, then create a custom connector

Gemini CLI

Gemini CLI keeps servers in a settings file and distinguishes streamable HTTP from SSE with separate keys.

~/.gemini/settings.json

Cursor

Cursor reads one JSON file per project or one global file, and handles local and remote servers in the same shape.

.cursor/mcp.json

VS Code with GitHub Copilot

VS Code uses its own key name and a typed entry, plus an inputs array that prompts for secrets instead of storing them.

.vscode/mcp.json

Windsurf

Windsurf Cascade reads a dedicated MCP config file and uses serverUrl rather than url for remote servers.

~/.codeium/windsurf/mcp_config.json

Codex CLI

Codex CLI is the only widely used client that configures MCP in TOML rather than JSON, which trips up copied snippets.

~/.codex/config.toml

Zed

Zed calls them context servers and nests them inside the editor settings file rather than a dedicated MCP file.

~/.config/zed/settings.json

Every entry above was read from the vendor documentation linked on its page, on the date shown there. ConnectorZone is not affiliated with any of these vendors.
