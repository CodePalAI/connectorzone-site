ChatGPT and the OpenAI API

ChatGPT connectors and the OpenAI Responses API both attach remote MCP servers by URL. Neither runs a local process for you.

What it does well

  • A remote server reaches every device signed into the same account with no local install.
  • The Responses API accepts the same server URL, so a prototype in chat moves into code unchanged.
  • Approval behaviour is configurable per request when calling through the API.

What catches people out

  • Local stdio servers cannot be attached. The server must be reachable over HTTPS.
  • Custom connectors in ChatGPT sit behind developer mode and are not available on every plan.
  • The server must handle its own authentication, because there is no local environment block to inject secrets into.

A working example

This is the real block for AIOProductOS MCP, generated from its registry record. Every connector profile produces the same thing for whichever client you are using.

Responses API request
{
  "model": "gpt-5.1",
  "tools": [
    {
      "type": "mcp",
      "server_label": "mcp",
      "server_url": "https://platform.aioproductos.com/api/mcp",
      "require_approval": "always"
    }
  ],
  "input": "List the tools this connector exposes."
}

Setting up a server

  1. Confirm the connector publishes a public HTTPS endpoint. Local only servers will not work here.
  2. In ChatGPT open Settings, then Connectors, then add a custom connector using the URL below.
  3. Complete any authorisation prompt the server presents, then enable the connector in a new chat.
