Data endpoints

Static files, no rate limit, no key. A full catalog index and one document per profile.

Endpoints

PathWhat it holds
/api/connectors.jsonEvery published profile with its normalised facts. 14,240 entries.
/api/connectors/{slug}.jsonOne profile in full, including install options, per client verdicts and the score breakdown.
/api/clients.jsonThe nine client definitions: dialect, transports, config paths and documentation links.
/api/stats.jsonCatalog counts and snapshot metadata, the same numbers shown on the status page.
/search-index.jsonCompact search index used by the search box. Slug, name, publisher and keywords only.

Example

Terminal
curl -s https://connector.zone/api/connectors.json \
  | jq '.connectors | map(select(.auth == "oauth")) | length'

Terms

  • Free to use, no key, no rate limit beyond what the static host applies.
  • Cache responses. These files change only when the registry snapshot changes.
  • Attribute the source. Registry records are CC0 1.0 from the official Model Context Protocol Registry, and the normalised fields are ConnectorZone work.
  • For bulk registry data, read the registry directly rather than crawling this site. It is the upstream source and it will always be more current.

Stability

Slugs are derived deterministically from registry names and do not change when other connectors are added or removed, so a URL you save today keeps working. Fields may be added. Existing fields will not be renamed without an entry on the changelog.
