Research connectors that cite their sources

Retrieval connectors change what a model is willing to say. Given a search tool over primary sources, an assistant will quote and link rather than reconstruct from memory, and the failure mode shifts from confident invention to an honest empty result. That is a much better failure to have.

Before you attach any of these

  • Confirm whether the connector returns full text or only metadata, because the answer quality difference is large.
  • Public data is not always current data. Check how often the underlying source is refreshed.
  • Several of these wrap an upstream API with its own terms. Read them before building a product on top.

Membership is recalculated from the registry snapshot on every build, so a connector can enter or leave this set when its record changes. Read thesecurity guide before granting access to anything sensitive.
