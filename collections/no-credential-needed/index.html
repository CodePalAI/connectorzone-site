Connectors that need no credential

When a client will not load a server, the fastest way to find out whether the problem is the config file or the credential is to attach something that needs no credential at all. If a keyless connector loads and a keyed one does not, the file is fine and the secret is the problem.

Selection ruleNo environment variable, header or authorisation flow is declared anywhere in the record.

Before you attach any of these

  • No declared credential does not mean no rate limit. A hosted keyless endpoint will still throttle you.
  • A record can simply omit a credential it actually needs. If tools fail with an authorisation error, check the source.
  • Keyless does not mean harmless. A connector with no key can still read whatever you point it at.

Membership is recalculated from the registry snapshot on every build, so a connector can enter or leave this set when its record changes. Read thesecurity guide before granting access to anything sensitive.
