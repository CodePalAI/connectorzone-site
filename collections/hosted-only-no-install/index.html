Hosted connectors with nothing to install

Some clients will not run a local process at all, and some machines are locked down enough that installing one is a project of its own. A hosted endpoint sidesteps both problems: you paste a URL, complete an authorisation step, and the tools appear. The trade is that your requests now travel to somebody else infrastructure, so the operator of that endpoint matters more than the code does.

Before you attach any of these

  • Read who runs the endpoint. A hosted connector sees every argument your assistant sends it.
  • Prefer endpoints that use an authorisation flow over ones that want a long lived key pasted into a settings box.
  • Check whether the endpoint is rate limited per account or per key, because an agent loop will find that limit quickly.

Membership is recalculated from the registry snapshot on every build, so a connector can enter or leave this set when its record changes. Read thesecurity guide before granting access to anything sensitive.
