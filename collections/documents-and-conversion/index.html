Document and file conversion

File connectors are the quiet win of this catalog. They hold no long lived state, they usually need no access to your systems, and they close the gap between a model producing text and a person needing a document. They are a good place to start if you want to demonstrate value without a security review.

Before you attach any of these

  • Find out where uploaded files are stored and for how long, because a conversion service sees the whole document.
  • Large files and long running jobs interact badly with client timeouts. Check the size ceiling.
  • Verify checksums on any downloadable bundle before opening it.

Membership is recalculated from the registry snapshot on every build, so a connector can enter or leave this set when its record changes. Read thesecurity guide before granting access to anything sensitive.
