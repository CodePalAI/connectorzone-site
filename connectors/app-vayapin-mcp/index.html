    Values you supply

    • VAYAPIN_PATrequiredsecretVayaPin Personal Access Token, sent as 'Authorization: Bearer'. Generate one on the VayaPin developer portal (POST /api/v1/auth/pat/request).
    • VAYAPIN_MCP_SLICEOptional tool-slice name to expose a subset of tools (128-tool client ceiling lift). Unset exposes all tools.
    • VAYAPIN_MCP_API_URLOverride the VayaPin API base URL for staging or self-host.

Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@vayacore/mcp@0.1.2"
      ],
      "env": {
        "VAYAPIN_PAT": "<your-vayapin-pat>",
        "VAYAPIN_MCP_SLICE": "<vayapin-mcp-slice>",
        "VAYAPIN_MCP_API_URL": "https://api.vayapin.app/api/v1"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.
