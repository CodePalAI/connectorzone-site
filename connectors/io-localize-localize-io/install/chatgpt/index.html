Connect Localize.io to ChatGPT and the OpenAI API

Hosted at hub.localize.io over streamable HTTP. Needs a bearer token header, and it reaches 8 of 9 clients tracked here. This page covers the ChatGPT and the OpenAI API dialect specifically, because a block copied from another client will not load here.

Where the configuration lives

ChatGPT
Settings, then Connectors, then create a custom connector
OpenAI API
Responses API request body, tools array
Top level key
tools

The block to paste

Responses API request
{
  "model": "gpt-5.1",
  "tools": [
    {
      "type": "mcp",
      "server_label": "localize-io",
      "server_url": "https://hub.localize.io/mcp/",
      "require_approval": "always",
      "headers": {
        "Authorization": "<your-authorization>"
      }
    }
  ],
  "input": "List the tools this connector exposes."
}
  • In ChatGPT, add the URL above as a custom connector. The request body below is the equivalent call through the Responses API.
  • Keep require_approval set to always until you have watched the connector run and understand what it can reach.

Values you need to replace

NameRequiredWhat it is
AuthorizationYessecretLocalize.io API key as a bearer token: 'Bearer lh_...'. Create one in the app under Settings → API Keys.

Steps

  1. Confirm the connector publishes a public HTTPS endpoint. Local only servers will not work here.
  2. In ChatGPT open Settings, then Connectors, then add a custom connector using the URL below.
  3. Complete any authorisation prompt the server presents, then enable the connector in a new chat.

What to watch for in ChatGPT

  • Local stdio servers cannot be attached. The server must be reachable over HTTPS.
  • Custom connectors in ChatGPT sit behind developer mode and are not available on every plan.
  • The server must handle its own authentication, because there is no local environment block to inject secrets into.

Behaviour above was read from OpenAI platform documentation, connectors and MCP on 2026-07-30.

Before you connect it

Published under the verified namespace io.localize, which resolves to the same domain as the linked website. That pairing is the strongest ownership signal the registry exposes.

A bearer token is sent in a request header. Store it outside the config file wherever your client supports it.

A listing in the official registry is a namespace ownership check, not a security review. ConnectorZone does not execute connectors and does not audit their code. Treat every connector as third party software with the access you grant it.
