Connect valv to Windsurf

Runs locally from the npm package mcp. The credential requirement is not named, and it reaches 8 of 9 clients tracked here. This page covers the Windsurf dialect specifically, because a block copied from another client will not load here.

Where the configuration lives

macOS and Linux
~/.codeium/windsurf/mcp_config.json
Windows
%USERPROFILE%\.codeium\windsurf\mcp_config.json
Top level key
mcpServers

The block to paste

~/.codeium/windsurf/mcp_config.json
{
  "mcpServers": {
    "mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@valv/mcp@0.6.2"
      ],
      "env": {
        "DATABASE_URL": "<your-database-url>",
        "VALV_PROVIDER": "<valv-provider>",
        "VALV_DATABASE": "<valv-database>",
        "VALV_TABLES": "<valv-tables>",
        "VALV_EXCLUDE": "<valv-exclude>",
        "VALV_POLICY_FILE": "/absolute/path/to/target",
        "VALV_CONTEXT": "<valv-context>",
        "VALV_HTTP_PORT": "<valv-http-port>"
      }
    }
  }
}
  • Merge this into ~/.codeium/windsurf/mcp_config.json rather than replacing the file, so servers you already run keep working.

Values you need to replace

NameRequiredWhat it is
DATABASE_URLYessecretDatabase connection string. PostgreSQL, MySQL, SQLite, CockroachDB, or a ClickHouse HTTP URL.
VALV_PROVIDEROptionalDatasource provider: postgresql, mysql, sqlite, or clickhouse. Inferred from DATABASE_URL when omitted.
VALV_DATABASEOptionalDatabase name. Required for ClickHouse, whose URL does not carry one.
VALV_TABLESOptionalComma-separated allow-list of tables. When set, only these are exposed to the agent.
VALV_EXCLUDEOptionalComma-separated deny-list of tables, applied after the allow-list.
VALV_POLICY_FILEOptionalPath to a policy module that takes full control of access. Without it, the server is read-only across all tables.
VALV_CONTEXTOptionalJSON context object the policy reads, e.g. {"tenant":{"id":"acme"}}.
VALV_HTTP_PORTOptionalServe over Streamable HTTP on this port instead of stdio.

Steps

  1. Open Windsurf settings, find Cascade and choose the MCP servers panel.
  2. Select the raw configuration option and merge the block below.
  3. Refresh the server list and confirm the tool count is greater than zero.

What to watch for in Windsurf

  • Remote servers use serverUrl. A block copied from Cursor or Claude will not connect.
  • Cascade counts tools against a per conversation budget, so trim large servers.

Behaviour above was read from Windsurf documentation, Cascade MCP on 2026-07-30.

Before you connect it

Published under the verified namespace sh.valv, which resolves to the same domain as the linked website. That pairing is the strongest ownership signal the registry exposes.

The record marks at least one value as secret without naming the scheme. Read the source before you supply a credential.

A listing in the official registry is a namespace ownership check, not a security review. ConnectorZone does not execute connectors and does not audit their code. Treat every connector as third party software with the access you grant it.
