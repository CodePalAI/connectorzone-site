Install options

Every delivery method published in the registry record, with the command resolved from the package type.

  • npm package

    stdio
    Identifier
    @molpha/mcp
    Version
    0.1.2
    Command
    npx -y @molpha/mcp@0.1.2

    Values you supply

    • SIGNER_BACKENDrequiredSigning backend: memory (local keypair) or keychain (Privy / Turnkey).
    • OWNER_KEYPAIRPath to a Solana JSON keypair file. Required when SIGNER_BACKEND=memory.
    • KEYCHAIN_BACKENDKeychain provider: privy or turnkey. Required when SIGNER_BACKEND=keychain.
    • PRIVY_APP_IDsecretPrivy app ID. Required for KEYCHAIN_BACKEND=privy.
    • PRIVY_APP_SECRETsecretPrivy app secret. Required for KEYCHAIN_BACKEND=privy.
    • PRIVY_WALLET_IDsecretPrivy wallet ID. Required for KEYCHAIN_BACKEND=privy.
    • PRIVY_WALLET_ADDRESSSolana address for the Privy wallet.
    • TURNKEY_API_PUBLIC_KEYsecretTurnkey API public key. Required for KEYCHAIN_BACKEND=turnkey.
    • TURNKEY_API_PRIVATE_KEYsecretTurnkey API private key. Required for KEYCHAIN_BACKEND=turnkey.
    • TURNKEY_ORGANIZATION_IDsecretTurnkey organization ID. Required for KEYCHAIN_BACKEND=turnkey.
    • TURNKEY_WALLET_ADDRESSSolana address for the Turnkey wallet.
    • SOLANA_RPCSolana RPC endpoint.
    • GATEWAY_ENDPOINTSComma-separated Molpha gateway URLs. Leave empty to use the SDK default.
    • MOLPHA_EVM_NETWORKSComma-separated EVM verifier networks.
    • MOLPHA_STARKNET_NETWORKSComma-separated Starknet verifier networks.
    • MOLPHA_DRY_RUNPreview all write and spend operations without submitting them.
    • MOLPHA_MAX_EXECUTES_PER_DAYProcess-local daily Solana submit cap.
    • MOLPHA_X402_MAX_PRICE_USDCRefuse to fund an x402 round priced above this amount (decimal USDC).
    • MOLPHA_X402_MAX_SPEND_PER_DAY_USDCProcess-local daily x402 spend cap (decimal USDC).
    • MOLPHA_X402_GATEWAY_PDAOptional settling gateway PDA (base58) to skip discovery when the escrow is already funded.

Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "mcp": {
      "command": "npx",
      "args": [
        "-y",
        "@molpha/mcp@0.1.2"
      ],
      "env": {
        "SIGNER_BACKEND": "memory",
        "OWNER_KEYPAIR": "/absolute/path/to/target",
        "KEYCHAIN_BACKEND": "<keychain-backend>",
        "PRIVY_APP_ID": "<your-privy-app-id>",
        "PRIVY_APP_SECRET": "<your-privy-app-secret>",
        "PRIVY_WALLET_ID": "<your-privy-wallet-id>",
        "PRIVY_WALLET_ADDRESS": "<privy-wallet-address>",
        "TURNKEY_API_PUBLIC_KEY": "<your-turnkey-api-public-key>",
        "TURNKEY_API_PRIVATE_KEY": "<your-turnkey-api-private-key>",
        "TURNKEY_ORGANIZATION_ID": "<your-turnkey-organization-id>",
        "TURNKEY_WALLET_ADDRESS": "<turnkey-wallet-address>",
        "SOLANA_RPC": "https://api.devnet.solana.com",
        "GATEWAY_ENDPOINTS": "<gateway-endpoints>",
        "MOLPHA_EVM_NETWORKS": "evm-sepolia",
        "MOLPHA_STARKNET_NETWORKS": "starknet-sepolia",
        "MOLPHA_DRY_RUN": "false",
        "MOLPHA_MAX_EXECUTES_PER_DAY": "100",
        "MOLPHA_X402_MAX_PRICE_USDC": "1",
        "MOLPHA_X402_MAX_SPEND_PER_DAY_USDC": "10",
        "MOLPHA_X402_GATEWAY_PDA": "<molpha-x402-gateway-pda>"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.

Registry verified. Published from the molpha account, and the linked repository sits under the same account. Namespace ownership was proven at publish time.

A long lived key or token is required. Scope it as narrowly as the upstream service allows and rotate it on a schedule.
