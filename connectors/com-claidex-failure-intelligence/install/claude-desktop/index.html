Connect Claidex MCP to Claude Desktop

Hosted at app.claidex.com over streamable HTTP, also runs locally from the npm package claidex-mcp. Needs a bearer token header, and it reaches all 9 clients tracked here. This page covers the Claude Desktop dialect specifically, because a block copied from another client will not load here.

Where the configuration lives

macOS
~/Library/Application Support/Claude/claude_desktop_config.json
Windows
%APPDATA%\Claude\claude_desktop_config.json
Linux
~/.config/Claude/claude_desktop_config.json
Top level key
mcpServers

The block to paste

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "failure-intelligence": {
      "command": "npx",
      "args": [
        "-y",
        "@claidex-mcp/claidex-mcp@1.0.0"
      ],
      "env": {
        "CLAIDEX_MCP_URL": "https://app.claidex.com/api/mcp",
        "CLAIDEX_MCP_API_KEY": "<your-claidex-mcp-api-key>"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.

Values you need to replace

NameRequiredWhat it is
CLAIDEX_MCP_URLOptionalClaidex MCP endpoint URL.
CLAIDEX_MCP_API_KEYYessecretClaidex API key for protected tools and resources.

Steps

  1. Open Claude Desktop, then go to Settings and choose Developer.
  2. Select Edit Config to reveal claude_desktop_config.json in your file browser.
  3. Merge the block below into the file. Keep any servers that are already listed.
  4. Quit Claude Desktop completely and reopen it, then check the tools indicator in the composer.

What to watch for in Claude Desktop

  • The JSON file only configures local processes. Remote servers are added through the connector settings screen instead.
  • The app must be fully quit and reopened before it picks up a config change.
  • Environment variables in the file are stored in plain text, so treat the file as a secret.

Behaviour above was read from Model Context Protocol docs, connect local servers on 2026-07-30.

Before you connect it

Published under the verified namespace com.claidex, which resolves to the same domain as the linked website. That pairing is the strongest ownership signal the registry exposes.

A bearer token is sent in a request header. Store it outside the config file wherever your client supports it.

A listing in the official registry is a namespace ownership check, not a security review. ConnectorZone does not execute connectors and does not audit their code. Treat every connector as third party software with the access you grant it.
