Install options

Every delivery method published in the registry record, with the command resolved from the package type.

  • npm package

    stdio
    Identifier
    @saihm/mcp-server-pro
    Version
    0.2.1
    Command
    npx -y @saihm/mcp-server-pro@0.2.1

    Values you supply

    • SAIHM_ENDPOINT_URLSAIHM operator endpoint. Optional: defaults to the hosted service at https://saihm.coti.global/mcp.
    • SAIHM_SELF_JOINSelf-join is ON by default: the saihm_join tool generates a non-custodial identity on this device and activates the free trial, so no master secret is needed. Set to '0' to suppress the tool.
    • SAIHM_MASTER_SECRET_FILEsecretPath to a mode-600 file holding a 64+ hex-char master secret. Only needed if you opt out of self-join or are restoring an existing identity. Never transmitted.
    • SAIHM_HOMEBase dir for the self-join identity file ($SAIHM_HOME/free-identity.key, mode 600). Defaults to ~/.saihm.

Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "saihm-mcp-server-pro": {
      "command": "npx",
      "args": [
        "-y",
        "@saihm/mcp-server-pro@0.2.1"
      ],
      "env": {
        "SAIHM_ENDPOINT_URL": "https://saihm.coti.global/mcp",
        "SAIHM_SELF_JOIN": "<saihm-self-join>",
        "SAIHM_MASTER_SECRET_FILE": "<your-saihm-master-secret-file>",
        "SAIHM_HOME": "/absolute/path/to/target"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.
