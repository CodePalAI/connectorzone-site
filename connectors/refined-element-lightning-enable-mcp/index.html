Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "lightning-enable": {
      "command": "dnx",
      "args": [
        "LightningEnable.Mcp@1.21.0",
        "--yes"
      ],
      "env": {
        "STRIKE_API_KEY": "<your-strike-api-key>",
        "NWC_CONNECTION_STRING": "<your-nwc-connection-string>",
        "LND_REST_HOST": "<lnd-rest-host>",
        "LND_MACAROON_HEX": "<your-lnd-macaroon-hex>",
        "OPENNODE_API_KEY": "<your-opennode-api-key>",
        "OPENNODE_ENVIRONMENT": "production",
        "LIGHTNING_ENABLE_API_KEY": "<your-lightning-enable-api-key>",
        "AGENT_RELAY_URL": "wss://agents.lightningenable.com"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.

Registry verified. Published from the refined-element account, and the linked repository sits under the same account. Namespace ownership was proven at publish time.

A long lived key or token is required. Scope it as narrowly as the upstream service allows and rotate it on a schedule.
