Install options

Every delivery method published in the registry record, with the command resolved from the package type.

  • npm package

    stdio
    Identifier
    sub-agents-mcp
    Version
    0.12.0
    Command
    npx -y sub-agents-mcp@0.12.0

    Values you supply

    • AGENTS_DIRrequiredAbsolute path to the directory containing agent definition files (.md or .txt)
    • AGENT_TYPErequiredType of AI CLI to use: 'cursor', 'claude', 'gemini', 'codex', 'glm', 'kimi', 'grok', or 'opencode'
    • AGENT_PERMISSIONApproval/sandbox level for sub-agents: 'read-only', 'safe-edit' (default), or 'yolo'
    • AGENT_MODELOptional model override applied to every sub-agent execution by this MCP server
    • AGENT_EFFORTOptional backend-specific reasoning effort or model variant. Supported by codex, claude, glm, kimi, grok, and opencode.
    • CURSOR_API_KEYsecretAPI key for cursor-agent authentication (used only when AGENT_TYPE=cursor; passed via env, never via CLI args)
    • CLI_API_KEYsecretProvider API key for AGENT_TYPE=glm or kimi (passed to the claude binary via env, never via CLI args). Restart/reconnect the MCP server after changing it.
    • EXECUTION_TIMEOUT_MSMaximum execution time for agents in milliseconds (default: 300000, max: 600000)
    • SESSION_ENABLEDEnable session management to maintain execution history across agent calls (default: false)
    • SESSION_DIRDirectory path for storing session files (default: .mcp-sessions in current working directory)
    • SESSION_RETENTION_DAYSNumber of days to retain session history before automatic cleanup (default: 7)
    • AGENTS_SETTINGS_PATHPath to CLI settings file/directory. Claude: --settings arg, Cursor: CURSOR_CONFIG_DIR, Codex: CODEX_HOME. GLM/Kimi/Gemini/Grok/OpenCode not supported.

Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "sub-agents": {
      "command": "npx",
      "args": [
        "-y",
        "sub-agents-mcp@0.12.0"
      ],
      "env": {
        "AGENTS_DIR": "<agents-dir>",
        "AGENT_TYPE": "<agent-type>",
        "AGENT_PERMISSION": "<agent-permission>",
        "AGENT_MODEL": "<agent-model>",
        "AGENT_EFFORT": "<agent-effort>",
        "CURSOR_API_KEY": "<your-cursor-api-key>",
        "CLI_API_KEY": "<your-cli-api-key>",
        "EXECUTION_TIMEOUT_MS": "<execution-timeout-ms>",
        "SESSION_ENABLED": "<session-enabled>",
        "SESSION_DIR": "<session-dir>",
        "SESSION_RETENTION_DAYS": "<session-retention-days>",
        "AGENTS_SETTINGS_PATH": "<agents-settings-path>"
      }
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.

Registry verified. Published from the shinpr account, and the linked repository sits under the same account. Namespace ownership was proven at publish time.

A long lived key or token is required. Scope it as narrowly as the upstream service allows and rotate it on a schedule.
