Configuration

Written for Claude Desktop. Every other client that can reach this connector gets its own block in the compatibility table below.

~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "forge-cascade": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "ghcr.io/sunflash12/forge-cascade-mcp:v0.1.7"
      ]
    }
  }
}
  • Merge this into ~/Library/Application Support/Claude/claude_desktop_config.json rather than replacing the file, so servers you already run keep working.

A bearer token is sent in a request header. Store it outside the config file wherever your client supports it.
