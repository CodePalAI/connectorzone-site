What the publisher says

An MCP server that provides persistent multimodal context storage for LLM agents.

Registry description for io.github.alex-feel/mcp-context-server, version 2.2.2. Reused under CC0 1.0.

        "POOL_HEALTH_CHECK_INTERVAL_S": "<pool-health-check-interval-s>",

        "RETRY_BASE_DELAY_S": "<retry-base-delay-s>",
        "RETRY_MAX_DELAY_S": "<retry-max-delay-s>",
        "RETRY_JITTER": "<retry-jitter>",
        "RETRY_BACKOFF_FACTOR": "<retry-backoff-factor>",
