Submit a connector

There is no separate submission queue here. Publish to the official registry and the next sync collects your record.

The short version

ConnectorZone does not maintain its own list of connectors. Every profile comes from the official Model Context Protocol Registry. If your connector is published there and the record is complete, it appears here after the next sync.

That is deliberate. A second submission queue would mean a second source of truth, and catalogs that maintain their own lists drift away from the registry within months.

Publish to the official registry

Follow the publishing documentation atmodelcontextprotocol.io. You will need to prove ownership of a namespace, either a GitHub account for anio.github. name or a domain for a company name.

What makes a record earn a good page here

Our gates are published on the methodology page. In practice, five fields do most of the work:

  • A description of at least 45 characters that says what the connector reaches, not what MCP is.
  • A repository URL, so a reader can check the claim.
  • A website URL, which is also what promotes a record to vendor published when the domain matches your namespace.
  • A pinned package version, so the generated config is reproducible.
  • Environment variables with descriptions and correct isSecret flags.

A record that scores well

server.json
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/weather",
  "title": "Example Weather",
  "description": "Forecasts, historical observations and severe weather alerts for any coordinate.",
  "version": "1.2.0",
  "websiteUrl": "https://example.com/mcp",
  "repository": {
    "url": "https://github.com/example/weather-mcp",
    "source": "github"
  },
  "packages": [
    {
      "registryType": "npm",
      "identifier": "@example/weather-mcp",
      "version": "1.2.0",
      "transport": { "type": "stdio" },
      "environmentVariables": [
        {
          "name": "WEATHER_API_KEY",
          "description": "Key from the Example dashboard, read scope is enough.",
          "isRequired": true,
          "isSecret": true
        }
      ]
    }
  ]
}

Something is wrong with a page here

Open an issue and we will fix or remove it. This is the fastest route for a wrong compatibility verdict, a miscategorised connector or an install command that does not work.
